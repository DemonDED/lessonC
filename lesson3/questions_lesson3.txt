a) Повторение, управляемое счетчиком, также называется ОПРЕДЕЛЕННЫМ повторением, поскольку заранее известно, сколько раз будет выполнен цикл.

b) Повторение, управляемое контрольным значением, также называется НЕОПРЕДЕЛЕННЫМ повторением, поскальку заранее не известно, сколько раз будет выполнен цикл.

c) В повторении, управляемом счетчиком, для подсчета числа повторений группы команд используется СЧЕТЧИК.

d) Оператор CONTINUE при его исполнении в операторе повторения вызывает немедленное выполнение следующей итерации цикла.

e) Оператор BREAK при его исполнении в операторе повторения или операторов switch вызывает немедленный выход из управляющей структуры.

f) SWITCH используется для проверки данной переменной или выражения на равенство каждому из постоянных целочисленных значений, которые они могут принимать.

Верно или неверно

a) В операторе выбора switch необходим блок default - не верно, т.к. без блока default оператор все равно будет работать с указанными case, default лишь выполняет код в случае отсуствия совпадений с указанными case

b) В блоке default оператора выбора switch необходим оператор break - неверно, т.к. блок default является выходом из оператора switch, break не является обязательным если default является последним блоком.

c) Выражение (x > y && a < b) истинно, если истинно либо выражение x > y, либо выражение a < b - неверно, т.к. && (логическое И) истиноо только в случае истинности обоих выражений.
