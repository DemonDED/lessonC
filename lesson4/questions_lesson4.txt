Модуль программы на С называется ФУНКЦИЕЙ

Обращение к функциям осуществляется посредством ВЫЗОВА ФУНКЦИИ

Переменная, которая известная только внутри функции, в которой она определена, называется ЛОКАЛЬНОЙ

Оператор RETURN в вызываемой функции используется для передачи значения выражения вызывающей функции

Ключевое слово VOID используется в заголовке функции, чтобы показать, что функция не возвращает значения или не содержит никаких параметров

ОБЛАСТЬ ДЕЙСТВИЯ идентификатора является частью программы, в которой идентификатор может быть использован

Тремя способами возврата управления от вызываемой функции к вызывающей являются }, RETURN;, RETURN выражение

ПРОТОТИП ФУНКЦИИ позволяет компилятору проверять число, типы и порядок следования аргументов, переданных функции

Функция RAND используется для генерации случайных чисел
Функция SRAND устанавливает семя генератора случайных чисел для рандомизации программы

Спецификаторами класса памяти являются AUTO, REGISTER, STATIC, EXTERN

Предполагается, что переменные, объявленные в блоке или в списке параметров функции, имеют АВТОМАТИЧЕСКИЙ класс памяти, если не указано иначе

Спецификатор класса памяти REGISTER рекомендует компилятору разместить переменную в одном из регистров компьютера

Переменная, определенная вне любого блока или функции, является ГЛОБАЛЬНОЙ переменной

Чтобы локальная переменная в функции сохраняла свое значение между вызовами функции, она должна быть объявлена со спецификатором класса памяти STATIC

Четыремя возможными областями действия идентификатора являются ФУНКЦИИ, ФАЙЛА, БЛОКА, ПРОТОТИПА

Функция, которая вызывает саму себя или непосредственно, или косвенно, является РЕКУРСИВНОЙ функцией

Рекурсивная функция обычно имеет два компонента: один компонент задает условие завершения рекурсии, проверяя текущую задачу на ОСНОВНОЙ случай, а второй компонент упрощает задачу для выполнения очередного рекурсивного вызова
